## 2. Technical Validation Rules for Guides

Every guide is validated by `src/lib/guides/guides.ts` and tested via `npm test` (`src/lib/guides/guides.test.ts`). **A single formatting violation will fail the build.**

| Field | Rule & Constraint | Example |
| :--- | :--- | :--- |
| `slug` | Lowercase kebab-case; **must match file name exactly** | `compress-image-to-20kb-or-50kb` |
| `title` | **Maximum 47 characters** (Astro appends ` \| TommyTools`, keeping `<title>` ≤ 60 chars) | `"How to compress image to 20KB or 50KB"` (37 chars) |
| `description` | **50 to 160 characters** | Plain meta description for Google SERPs |
| `publishDate` | ISO Date format `YYYY-MM-DD` (UTC) | `"2026-11-02"` |
| `tool` | **Must match exactly one live tool slug** | `work-hours`, `image-resizer`, `image-compressor`, `signature-formatter`, `merge-pdf`, `split-pdf`, `advertising-metrics`, `freelancer-rate`, `ai-system-risk-checklist`, `nist-ai-rmf-checklist`, `owasp-llm-top10-checklist` |
| `lede` | One-sentence summary under H1 | Plain text |
| `problem` | User problem statement | Plain text (why spreadsheets/uploads fail) |
| `steps` | **Array of ≥ 2 items**, each `{ title, body }` | Step-by-step instructions |
| `limitations` | **Array of ≥ 1 string** | Real limitations of in-browser processing |
| `faq` | **Array of ≥ 1 item**, each `{ q, a }` | Real user questions |
| *Formatting* | **Strictly plain text only**. **NO HTML tags** (`<` or `>` will fail validation). |

## 3. Guide JSON Template

Copy this clean template when generating a guide in `src/content/guides/<slug>.json`:

```json
{
  "slug": "target-slug",
  "title": "Short Title Under 47 Chars",
  "description": "Accurate meta description between 50 and 160 characters describing the task and solution.",
  "lede": "One clear sentence summarizing how to solve the problem with the tool.",
  "publishDate": "YYYY-MM-DD",
  "tool": "live-tool-slug",
  "problem": "Explain why this task is frustrating or error-prone with standard software.",
  "steps": [
    {
      "title": "Step 1 Title",
      "body": "Step 1 clear explanation."
    },
    {
      "title": "Step 2 Title",
      "body": "Step 2 clear explanation."
    }
  ],
  "example": "Worked numeric example demonstrating the exact arithmetic or workflow.",
  "limitations": [
    "State real limitation of the tool (e.g. file size caps, client memory limits)."
  ],
  "faq": [
    {
      "q": "Frequently asked question?",
      "a": "Direct, plain answer without jargon."
    }
  ]
}
```

## 5. Automated Build & Quality Gate

Before completing any guide task:
1. Run unit tests:
   ```bash
   npm test
   ```
2. Verify Astro schema & types:
   ```bash
   npx astro check
   ```
3. Run local static production build:
   ```bash
   npm run build
   ```
   *Note: If testing on an environment without global node access, verify file syntax and character limits directly against `src/lib/guides/guides.ts`.*
